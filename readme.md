# kweebitect: tui hytale json composer

compose json asset files from directly in your projects, through the command line!

[![](https://img.shields.io/badge/Ratatui-000?logo=ratatui&logoColor=b55088&style=for-the-badge)](https://ratatui.rs/) <sup>*built wit advanced rat tech!*</sup>

if you hate working wit json, can't stand the deeply nested structures, despise not knowing *exactly* wot's possible at each step, yearn for prebuilt snippets, or simply get lost in massive metadata documentation lists... well dis hytale devtool fixes all dese things! endgame goal is essentially a platform for asset creation to rival even the official hytale gui editors!

prebuilt "snippets" from hypixel studios x hytale modding [documentation](https://hytalemodding.dev/en/docs/official-documentation/npc-doc)
